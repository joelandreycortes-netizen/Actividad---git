# Actividad---git
"Repositorio para la actividad de Git y GitHub 

## Descripción del proceso
En esta actividad creé un repositorio en GitHub para guardar y controlar los cambios de mis documentos, siguiendo estos pasos:

### 1. Crear cuenta en GitHub
Me registré en github.com con mi usuario y correo electrónico.

### 2. Instalar Git
Descargué e instalé Git desde git-scm.com en mi computadora para poder usar los comandos.

### 3. Crear repositorio
Entré a mi cuenta → "New repository" → Lo llamé `Actividad---git` → Marqué "Add a README file" → Crear repositorio.

### 4. Clonar en mi computadora
Copié el enlace HTTPS y en Git Bash escribí:
```bash
git clone https://github.com/joelandreycortes-netizen/Actividad---git.git

### 5. Crear y modificar documentos
Creé un archivo de texto llamado `mis-notas.txt` con un mensaje de prueba.

### 6. Subir los cambios
Intenté usar los comandos `git add`, `git commit` y `git push`, pero tuve dificultades con la configuración de identidad. Finalmente, subí el archivo directamente desde la página de GitHub arrastrándolo.

### Dificultades y soluciones
- No reconocía el comando `git` → Se solucionó instalando Git correctamente.
- Pedía configurar nombre y correo → Opté por subir el archivo directamente desde la web.
- Errores al escribir los comandos → Corregí espacios y comillas.

### Conclusión
Aprendí a usar Git y GitHub para guardar y controlar los cambios de mis proyectos Aunque los comandos parecían difíciles al principio, descubrí que también se pueden subir archivos directamente desde la página web.
